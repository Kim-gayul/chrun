# 검증 기록

검증일: 2026-10-03 · Windows · CPython 3.13.13.

## 통과한 검증

- 회귀 테스트 4개: 분할의 독립성·재현성, 입력 검증·범주 일치·음수 보정, 조기 종료 검증 데이터 전달, 실제 LightGBM 튜닝·학습·단건 예측.
- 모든 공개본 Python 파일의 문법 검사.
- Markdown의 로컬 문서·이미지 링크 존재 검사.
- 원 프로젝트 로컬 CSV 100,000행으로 학습·튜닝·테스트 평가.
- Streamlit AppTest로 데이터 누락 안내, 성능 표시, 예측 버튼, 튜닝 버튼 확인.
- 홍보 이미지의 텍스트·레이아웃 시각 확인.

실제 데이터의 해시, 선택된 파라미터와 테스트 지표는 `verification.json`에 기록했습니다. 원본 데이터는 검증 때 읽기만 했으며 공개본에 포함하지 않았습니다.

설치된 데모 패키지는 `requirements-lock.txt`에 기록했습니다. 추가 모델용 패키지는 이 검증 환경에 설치하지 않았습니다.

## 범위와 제한

Streamlit 검증은 AppTest 기반이며 브라우저 픽셀 수준의 화면 검증은 수행하지 않았습니다. 다른 4개 모델의 전체 학습 및 GPU 실행은 검증하지 않았습니다. 해당 코드는 원 팀의 실험 참고 자료로 제공됩니다.

LightGBM 4.7.0에서 `eval_set` 사용 중 deprecation 경고가 있지만 현재 학습은 통과했습니다. 요구 버전 범위의 4.x 호환성을 위해 이 API를 유지했습니다. AppTest의 bare-mode ScriptRunContext 경고도 발생했으며 앱 예외는 없었습니다.
