# 공개용 변경 기록

- 원본 작업 폴더와 Git 이력을 공개용 사본에 복사하지 않음.
- 원본 CSV, 중복 데이터, pickle/PyTorch 모델 및 분할 데이터 제외.
- 개인 프로필 이미지, 팀 WBS, 이전 로고 제외. 기여 출처는 별도 문서로 유지.
- 기존 LightGBM 스크립트를 루트 `pipeline.py`로 통합하고 파일 기준 경로 사용.
- 60/20/20 계층 분할로 테스트 세트를 튜닝·조기 종료에서 분리.
- `TotalCharges` 음수 보정과 타깃·숫자·범주 검증 추가.
- 예측과 학습에 동일한 범주 정의 적용.
- 사용자 예측 때마다 재학습하던 동작을 Streamlit 리소스 캐시로 변경.
- 고정 성능 수치를 제거하고 실제 테스트 평가·데이터 크기 표시.
- 관리자라는 명칭을 모델 평가·튜닝으로 변경하고 인증 기능으로 오인할 요소 제거.
- 기존 보고서는 역사적 실험 기록임을 명시. 과거 결과를 새 파이프라인 성능으로 재사용하지 않음.
- README에서 구현하지 않은 Flask/TensorFlow 기술 스택과 인과·사업 성과 단정 제거.
- 추가 모델의 데이터 경로 수정 및 딥러닝 모델 장치·저장 경로 일치.
- 홍보 배너 신규 제작. 실제 UI 캡처가 아닌 컨셉 이미지임을 명시.

데이터 출처 페이지는 확인했으나 자동 열람으로 재배포 조건을 확인하지 못해 CSV를 제외했습니다. 팀 코드의 새로운 라이선스는 임의로 지정하지 않았습니다.
